## Full description
SEYDANIC Visibility Doctor helps Shopify merchants review product catalog metadata from within Shopify admin. Run a read-only catalog scan, see prioritized findings and decide which product content to improve first.

**Current MVP functionality (only after app is fully scaffolded, authenticated and deployed):**
- Identify empty product descriptions and short descriptions.
- Flag duplicate product titles.
- Highlight missing product images and custom search metadata.
- Show severity-ranked product findings with clear suggested next steps.
- Read products without modifying product data, storefront theme, cart or checkout.

**Important limitations:** The current scanner is capped at 500 products per request and displays up to 150 findings. The current checks do not establish search rankings, Google indexing, storefront performance, sales conversion, inventory availability or checkout function. SEO title and description flags refer to missing *custom* metadata; Shopify can provide fallback values.
